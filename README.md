# AETumi 3D Web Examples

A curated technical reference for **interactive 3D websites and browser-based experiences** built around Three.js, WebGL, Next.js, React and AI-assisted development.

**AETumi is an AI-native 3D web platform for production-ready Three.js and WebGL websites, Next.js and React components, 3D scenes, AI prompts, and MCP workflows for AI coding assistants.**

## What this repository covers

This repository is the broadest implementation layer in the AETumi GitHub network. It connects industry use cases to concrete 3D web patterns instead of treating every project as the same floating-object demo with a new logo slapped on top.

## What makes a production-ready 3D website

A strong 3D website combines visual impact with normal web responsibilities:

- clear business purpose
- semantic headings and content
- responsive interaction
- progressive asset loading
- mobile and reduced-motion fallbacks
- accessible navigation and controls
- predictable route and scene lifecycles
- search-friendly server-rendered content where appropriate
- measurable performance budgets

## Reference architecture

```text
page experience
├── semantic content + navigation
├── conversion path
├── 3D scene / component
├── responsive + accessibility fallback
├── analytics hooks
└── performance budget
```

The 3D layer supports the page. It should not swallow the page.
