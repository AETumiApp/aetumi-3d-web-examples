# AETumi 3D Web Example Backlog

## Planned reference examples

### Ecommerce product launch

Semantic product page plus lazy-loaded Three.js hero, variant controls and analytics hooks.

### Luxury campaign page

Cinematic 3D direction with restrained interaction, progressive loading and mobile fallback.

### Automotive feature story

Camera chapters, feature hotspots and scroll-linked product reveal.

### Architecture presentation

Spatial scene paired with project narrative, materials and semantic case-study content.

### SaaS / technology hero

Shader or particle system used as a product metaphor without hiding the page's actual value proposition.

### Agency portfolio experience

A reusable case-study pattern where 3D reinforces project storytelling and conversion.

## Evaluation criteria

Each reference should explain:

- user goal
- 3D role
- semantic content boundary
- interaction model
- responsive fallback
- accessibility considerations
- performance budget
- analytics opportunity
